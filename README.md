# 🌦 Weather Forecast App

A simple and interactive **Streamlit web app** that provides weather forecasts for the next 1–5 days.  
You can visualize **temperature trends** or view **sky conditions** (clear, cloudy, rainy, snowy) with icons.

---

## 🚀 Features
- Enter any **place** (city name, e.g., *London, New York, Delhi*).
- Choose how many days (1 to 5) of forecast you want.
- View:
  - 📈 **Temperature trends** (line chart with Plotly).
  - ☁️ **Sky conditions** with images (clear, cloudy, rain, snow).
- Error handling for invalid locations.

---

## 🛠 Tech Stack
- [Streamlit](https://streamlit.io/) – for building the web app  
- [Plotly Express](https://plotly.com/python/plotly-express/) – for data visualization  
- [Requests / API](https://openweathermap.org/forecast5) – (in backend) to fetch forecast data
